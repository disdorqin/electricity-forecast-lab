# 6. Preprocessing / numerical stability

所有 state 只由 Stage-A BASE_TRAIN 拟合：

~~~text
median imputation
robust center/scale
PLE bins
temporal scaler
c_mag
~~~

Magnitude：

~~~text
c_mag=max(IQR(Y_BASE)/1.349,eps)
A_scaled=|Y|/c_mag
~~~

正式 numeric contract：

~~~text
raw
-> BASE_TRAIN median
-> BASE_TRAIN robust scale
-> clip
-> PLE / encoder
~~~

默认：

~~~text
future_clip_abs=10.0
temporal_clip_abs=10.0
~~~

每个真实 run 保存：

~~~text
numerical_audit.json
~~~

至少记录：

~~~text
preclip p99
preclip p99.9
preclip max
postclip max
clip count/fraction
top extreme features
~~~

已验收：

~~~text
future postclip max=10.0
temporal postclip max=10.0
all model inputs finite
~~~

真实 PLE 中 solar_drop_load_rise 可能产生 single-bin 官方 warning；
当前定性：

~~~text
NON_BLOCKING_DIAGNOSTIC
~~~

不得仅为消 warning 修改 selector、F10 或 PLE 语义。

# 7. Model runtime toggles

以下开关均已连接真实代码：

~~~text
ple_enabled
fft_enabled
future_conditioning
~~~

要求：

~~~text
PLE OFF
-> 不创建/使用 PLE

FFT OFF
-> temporal FFT residual bypass

future_conditioning OFF
-> H_time 不读取 target-day future conditioning
~~~

toggle 必须保持 tensor shape 与 finite。

# 8. V2.1 runtime contract

Tabular：

~~~text
official TabM-mini
H_tab=[B,k,24,d_tab]
~~~

Temporal：

~~~text
H_time=[B,24,d_time]
~~~

Direction：

~~~text
z_members=[B,k,24]
p_members=sigmoid(z_members)
p_hat=mean_k(p_members)
direction_hat=p_hat>=0.5
~~~

Magnitude：

~~~text
a_scaled_members=[B,k,24]
magnitude_hat=c_mag*mean_k(a_scaled_members)
~~~

Loss：

~~~text
L_dir=member-wise unweighted BCEWithLogits
L_mag=member-wise L1
L_total=lambda_dir*L_dir+lambda_mag*L_mag
~~~

canonical 不使用：

~~~text
class-weighted BCE
m_pos/m_nonpos
signed L_point
~~~

# 9. Checkpoint rule

当前正式规则：

~~~text
checkpoint_raw_tolerance=0.02
~~~

维护：

~~~text
raw_anchor=max monitor Raw observed so far
~~~

selected checkpoint 必须：

~~~text
selected.Raw >= raw_anchor - 0.02
~~~

guardrail 内：

~~~text
lower Magnitude MAE
-> lower L_total
-> earlier epoch
~~~

early-stopping progress：

~~~text
raw_anchor improves
OR selected checkpoint improves
~~~

禁止事后构造 weighted composite score。
