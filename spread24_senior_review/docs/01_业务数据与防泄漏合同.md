## 2. Source-native 与 Model target

当前 frozen source 不修改：

```text
Y_source = DA - RT
```

V2 通过明确 adapter：

```text
Y_model = -Y_source = RT - DA
```

因此：

- frozen parquet/hash 不变；
- source audit 继续按 DA-RT 审计；
- V2 direction/metric/training label 按 RT-DA；
- magnitude `|Y|` 不受整体翻号影响；
- 历史 DA-RT 的 +Recall/-Recall 与 V2 RT-DA 不得直接按名字比较。

## 3. 时间边界

对任意 target day D：

```text
origin        = D-1 14:00
history_start = D-8 15:00
history_end   = D-1 14:00
history_count = 168
```

24 个 target horizon 共用同一个 history cutoff。

监督训练 target day S：

```text
S <= D-2
```

允许：

- D-2 及更早完整 realized/label/history；
- D-1 h1..h14 已发生 context；
- D 日在 D-1 14:00 前已发布的 forecast-type fundamentals；
- calendar / hour 等确定性未来信息。

禁止：

- D-1 h15..h24 realized；
- D 日 RT / Spread / actual fundamentals；
- target-day actual 的任何派生量；
- D-1 完整 24 点 label；
- 上述未来信息进入 selector、threshold、calibration、checkpoint、early stop、router、ensemble weight。

target-day DA feature 当前仍禁止。
