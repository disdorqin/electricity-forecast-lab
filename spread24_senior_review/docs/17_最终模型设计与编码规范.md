# 1. 正式任务与 KPI

~~~
Y = RT - DA
D = 1[Y > 0]
A = |Y|
~~~

正式 KPI：

~~~
KPI-1 = Raw Direction Accuracy
KPI-2 = Magnitude MAE
~~~

zero policy：

~~~
Y > 0  -> positive
Y <= 0 -> non-positive
~~~

核心规则：selector、head、loss、checkpoint、readout 都必须直接服务 Direction 或 Magnitude 两个 KPI。Signed Spread 仍输出，但不再作为 canonical 训练目标。

# 2. 输入与边界

~~~
X_hist   [B,168,7]
X_future [B,24,259]
Y_source [B,24] = DA-RT
Y_model  [B,24] = RT-DA = -Y_source
~~~

24 horizon 共用 D-8 15:00 至 D-1 14:00 的 168h history。
监督标签仅允许 S <= D-2。
selected manifest 冻结后，只要 selected feature 存在 unresolved quarantined cell，该 sample/day 不得进入正式训练/评价；未选中污染字段不得误杀整日。

# 3. V2.1 核心研究假设

只保留两个模型核心：

1. Tabular State Encoder + Temporal Regime Encoder 的双编码；
2. Direction / Magnitude 两任务通过两个 global scalar 做轻量 cross-injection。

~~~
Direction = temporal primary + tabular auxiliary
Magnitude = tabular primary + temporal auxiliary
~~~

PLE、FFT、future conditioning、Stage B、TabM-mini/k、shadow policy、selector threshold 都只是工程配置或消融，不包装成核心创新。

# 4. Selector：DIR + MAG-ALL

canonical selector：

~~~
XGB-DIR
target = 1[Y>0]

XGB-MAG-ALL
target = |Y| / c_mag_fold
~~~

MAG-POS / MAG-NONPOS 只允许作为 diagnostics/ablation。

要求：

- chronological folds；
- validation OOS TreeSHAP；
- Boruta-style shadow；
- fixed seed；
- selector cutoff/folds/source hashes 写 manifest；
- 禁止 random CV。

每 fold：

~~~
c_mag_fold = max(IQR(Y_train)/1.349, eps)
~~~

shadow 工程默认：

~~~
within-hour across-day permutation
~~~

保留 global shuffle / day-profile block shuffle 作为后续单轴对照。

工程默认：

~~~
shadow_q = 0.90
Strong hit_rate >= 0.75
Weak 0.50 <= hit_rate < 0.75
Noise hit_rate < 0.50
~~~

强制保留 business_core 与 temporal_whitelist。

角色：

~~~
Strong-DIR
Strong-MAG
Strong-BOTH
Weak
Noise
Forced-Core
Forced-Temporal
~~~

最终 Selected = Strong(any) union Weak union business_core union temporal_whitelist。

# 5. Preprocessing

所有拟合 state 只来自 Stage-A BASE_TRAIN。

~~~
future median/imputation
future robust center/scale
temporal median/scale
optional PLE
c_mag
~~~

robust scaling：

~~~
center = median
scale  = max(IQR/1.349, eps)
~~~

Magnitude：

~~~
c_mag = max(IQR(Y_BASE)/1.349, eps)
A_scaled = |Y| / c_mag
~~~

Direction 不再拟合 class weights。

PLE 工程默认 ON、16 bins，但必须可关闭。

正式 future 与 temporal numeric inputs 必须在 BASE_TRAIN-only median/imputation + robust scaling 后 clip：

~~~text
future_clip_abs = 10.0
temporal_clip_abs = 10.0
clip_after_robust_scale = true
~~~

PLE bins 仅使用 clip 后的 BASE_TRAIN normalized future 拟合。每次真实训练写 numerical_audit.json，记录 preclip 分位数/max、postclip max、clip count/fraction、feature/channel median 与 robust scale；所有 transform 必须 finite 且 postclip max <= 10.000001。

# 7. Tabular / State Encoder

Strong/Core 使用 official tabm package，禁止 substitute。

~~~
x_future_selected [B,24,F]
-> flatten [B*24,F]
-> official ensemble before first feature-mixing layer
-> H_strong_flat [B*24,k,d_tab]
-> H_strong [B,k,24,d_tab]
~~~

工程默认：

~~~
tabm-mini
k=8
d_tab approximately 128
small depth
~~~

这些是 first-run default，不是科研结论。

Weak path：

~~~
weak features
-> small MLP
-> H_weak [B,24,d_tab]
-> broadcast k
~~~

Tabular 内部 Strong/Weak gate：

~~~
g_h = sigmoid(b_h)
init approximately 0.8

H_tab[:,:,h,:] =
g_h * H_strong[:,:,h,:]
+ (1-g_h) * H_weak[:,None,h,:]
~~~

# 8. Temporal / Regime Encoder

输入 X_hist [B,168,7]。

三组：

~~~
G_price:
  realized spread

G_demand:
  fcast_直调负荷
  fcast_竞价空间
  residual_load_renew

G_renewable:
  fcast_风电总加
  fcast_光伏总加
  fcast_新能源总加
~~~

core path：

~~~
per feature [B,168]
-> group-shared Linear(168,64)
-> GELU
-> Linear(64,24)
-> U_raw_f [B,24]
~~~

FFT 工程默认 ON：

~~~
bins = [1,7,14,21,28]
U_f = U_raw_f + rho_group * U_fft_f
~~~

future conditioning 仅使用 forecast-origin 时合法 target-day forecast；historical realized spread 禁止 target-day spread conditioning。

~~~
U_stack [B,24,7]
-> Linear(7,d_time)
-> GELU
-> H_time [B,24,d_time]

d_time default = 32
~~~

FFT 与 future conditioning 都必须可关闭。

# 9. Member-wise Direction Adapter

V2.1 不再在 Direction head 前 mean_k(H_tab)。

~~~
T_dir = P_time_dir(H_time)
[B,24,d_task]
-> broadcast [B,k,24,d_task]

S_dir = P_tab_dir(H_tab)
[B,k,24,d_task]

alpha_dir = sigmoid(a_dir)

H_dir_i =
alpha_dir*T_dir_i
+ (1-alpha_dir)*S_dir_i
~~~

~~~
z_i = Head_dir(H_dir_i)
p_i = sigmoid(z_i)

p_hat = mean_k(p_i)
direction_hat = p_hat >= 0.5
~~~

Direction ensemble 采用 member probability averaging。

diagnostics：

~~~
direction_member_std
direction_vote_fraction
direction_vote_entropy
~~~

# 10. Member-wise Magnitude Adapter

~~~
S_mag = P_tab_mag(H_tab)
T_mag = broadcast(P_time_mag(H_time))

alpha_mag = sigmoid(a_mag)

H_mag_i =
alpha_mag*S_mag_i
+ (1-alpha_mag)*T_mag_i
~~~

direct magnitude head：

~~~
a_scaled_i =
softplus(Head_mag(H_mag_i))
[B,k,24]

magnitude_scaled_hat = mean_k(a_scaled_i)
magnitude_hat = c_mag * magnitude_scaled_hat
~~~

V2.1 canonical 不再使用 m_pos / m_nonpos，也不使用 p*m_pos+(1-p)*m_nonpos 作为 Magnitude。

# 12. KPI-aligned Loss

Direction：

~~~
L_dir =
mean BCEWithLogits(z_members, D)
~~~

不使用 class weights。weighted BCE 仅允许独立 ablation。

Magnitude：

~~~
L_mag =
mean L1(a_scaled_members, A_scaled)
~~~

SmoothL1 只作为独立 ablation。

Total：

~~~
L_total =
lambda_dir * L_dir
+ lambda_mag * L_mag

lambda_dir=1
lambda_mag=1
~~~

V2.1 canonical 不使用 signed point loss。

可选 signed auxiliary 只能作为后续 ablation：

~~~
lambda_signed in {0.05, 0.10}
~~~

# 13. 正式 Readout

~~~
p_hat = mean_k(sigmoid(z_i))
direction_hat = p_hat >= 0.5

magnitude_hat =
c_mag * mean_k(a_scaled_i)

signed_kpi_hat =
+magnitude_hat if direction_hat
-magnitude_hat otherwise
~~~

实现时对 magnitude 使用极小 magnitude_eps 保证严格 sign ownership。

~~~
sign(signed_kpi_hat) -> Direction Head
abs(signed_kpi_hat)  -> Magnitude Head
~~~

旧 y_soft_train / m_pos / m_nonpos 不再属于 canonical output。

# 15. KPI-aligned checkpoint

每 epoch 在 MONITOR 计算：

~~~
Raw
Balanced
+Recall
-Recall
AUC
Brier
Magnitude MAE
L_dir
L_mag
L_total
~~~

checkpoint 使用 Raw guardrail + KPI lexicographic rule：

~~~text
checkpoint_raw_tolerance = 0.02
raw_anchor = max(Raw observed)
selected checkpoint 必须满足 Raw >= raw_anchor - checkpoint_raw_tolerance
在 guardrail 内：minimize Magnitude MAE -> minimize L_total -> earlier epoch
~~~

新 raw_anchor 使旧 selected checkpoint 越出 2pp guardrail 时，旧 checkpoint 立即失去资格。只有 raw_anchor 或 selected checkpoint 均无改善时 stale 才累积。early stop 依此 stale 规则执行。

禁止事后构造任意加权 composite score。

# 16. Stage B：实现，但不预设有效

Stage B 是 training enhancement，不是 V2.1 architecture 核心。

第一轮比较：

~~~
TRAIN-A = Stage A only
TRAIN-B = Stage A + Stage B
TRAIN-C = Full Retrain
~~~

只有 TRAIN-B 在更大 DEV 中稳定增益后，才可晋升 production default。

如启用 Stage B：

~~~
recent20 quota=80%
BASE replay=20%
epochs=8
lr=0.1*StageA lr
no early stopping
~~~

冻结 selector、preprocessing、c_mag、PLE、TabM shared backbone/front projection。

训练 official TabM 可安全识别的 member-specific params、Weak path、Strong/Weak gates、Temporal encoder、task adapters、Direction/Magnitude heads。

若无法可靠识别 member-specific params，冻结整个 TabM backbone并写 manifest，禁止按参数名猜。
