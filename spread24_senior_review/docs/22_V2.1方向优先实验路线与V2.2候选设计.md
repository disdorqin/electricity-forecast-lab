# 1. 业务目标：Direction Primary，Magnitude Secondary

~~~text
D = 1[RT-DA > 0]
A = |RT-DA|
~~~

正式研究优先级：

~~~text
PRIMARY:
Raw Direction Accuracy

DIRECTION SAFETY DIAGNOSTICS:
Balanced Accuracy
Positive Recall
Non-positive Recall
Direction BCE
AUC / Brier

SECONDARY:
Magnitude MAE
Magnitude RMSE / tail MAE
~~~

研究假设：

> Direction 决定交易方向；Magnitude 只有在 Direction 可用时才具有完整决策价值。

因此下一阶段不再默认把 Direction/Magnitude 当成完全对称的 multi-task objective。
但实验确认前，不直接修改 V2.1 canonical。

# 2. 文献依据

## 2.1 电力市场的 wrong-sign 代价

Serafin & Weron, Energy Economics 2025:
Loss functions in regression models: Impact on profits and risk in day-ahead electricity trading

https://www.sciencedirect.com/science/article/pii/S0140988325004207

该研究引入对 price-spread wrong-sign 的额外惩罚，并报告其交易表现优于多种常规回归损失。

启发：

~~~text
spread sign 不是普通附属指标；
wrong-sign prediction 具有不对称业务代价。
~~~

不能直接照搬其损失，因为市场、资产和数据与本项目不同。

## 2.2 山东现货价差方向研究

Price Spread Direction Prediction Based on an Improved LSTM Model in China’s Electricity Spot Market
ICPE 2024 / IEEE Xplore

https://ieeexplore.ieee.org/document/10929104/

该工作使用山东实际数据验证价差方向模型，并同时讨论分类指标与回测收益。

启发：

~~~text
直接建模 spread direction 在山东现货场景有业务与研究基础。
~~~

## 2.3 非对称多任务学习

Lee et al., ICML 2016:
Asymmetric Multi-task Learning Based on Task Relatedness and Loss

https://proceedings.mlr.press/v48/leeb16.html

启发：

~~~text
任务之间不必对称共享；
可以设计有方向的 transfer 以减少 negative transfer。
~~~

本项目只借用非对称共享原则，不复现其原始 sparse directed graph。

## 2.4 梯度冲突

Yu et al., NeurIPS 2020:
Gradient Surgery for Multi-Task Learning

https://papers.nips.cc/paper/2020/hash/3fe78a8acf5fda99de95303940a2420c-Abstract.html

核心诊断：

~~~text
gradient conflict:
cos(g_dir, g_mag) < 0
~~~

本项目先诊断，再决定是否需要 gradient protection。

## 2.5 固定 loss 权重不足以表达优先级

Chen et al., ICML 2018:
GradNorm

https://proceedings.mlr.press/v80/chen18a.html

启发：

~~~text
不同任务 loss 尺度与学习速度不同；
固定 lambda_dir:lambda_mag 不等价于真实业务优先级。
~~~

因此不采用简单 lambda_dir=5 作为主要 Direction-first 方法。

## 2.6 Lexicographic objective

Abernethy, Schapire, Syed, AISTATS 2024:
Lexicographic Optimization: Algorithms and Stability

https://proceedings.mlr.press/v238/abernethy24a.html

借用原则：

~~~text
先优化最高优先级目标，
再在该目标约束下优化次级目标。
~~~

不宣称直接复现其算法。

# 8. Gate E1-G：shared-gradient conflict diagnosis

只诊断，不改变 optimizer update。

指定少量 batch 分别计算：

~~~text
g_dir=grad(L_dir)
g_mag=grad(L_mag)
~~~

至少针对：

~~~text
tabular_encoder
temporal_encoder
~~~

记录：

~~~text
dot
cosine
dir_grad_norm
mag_grad_norm
norm_ratio
conflict=(cosine<0)
~~~

每 epoch 汇总：

~~~text
mean_cos
median_cos
conflict_rate
dir_grad_norm_mean
mag_grad_norm_mean
norm_ratio_median
~~~

约束：

- diagnostics 不得修改 optimizer gradient；
- diagnostics 不得改变数据顺序/seed；
- allow_unused 显式处理；
- 无梯度 group 写 N/A，不伪造 0。

默认：

~~~text
batches_per_epoch=2
~~~

# 10. Direction-first checkpoint candidate

V2.1 baseline：

~~~text
v21_guardrail:
raw_anchor
2pp tolerance
guardrail 内优先 Magnitude MAE
~~~

实验 candidate：

~~~text
direction_first:
1. maximize Raw Direction
2. Raw 完全相同时 minimize monitor L_dir
3. 再 minimize Magnitude MAE
4. 再 earlier epoch
~~~

不再允许低 1~2pp Raw 仅因 Magnitude 更好而替换更高 Raw checkpoint。

Balanced / +/-Recall 始终报告。
出现 one-class collapse 或极低 class recall 时必须显式标记，不能只看 Raw 宣布成功。

# 11. Direction-first early stopping candidate

checkpoint 和 convergence 分开。

progress：

~~~text
new Raw best
OR
(
  current Raw == best Raw
  AND monitor L_dir improves by >= direction_bce_min_delta
)
~~~

Magnitude MAE：

~~~text
不单独 reset patience
~~~

默认：

~~~text
direction_bce_min_delta=1e-4
~~~

仅作为工程起点。

# 12. Magnitude 可用性诊断

Direction-first 不等于 Magnitude 可以失效。

每个 run 计算 naive baseline：

~~~text
A_naive=median(|Y_BASE|)
MAE_naive=MAE(A_naive,|Y_monitor|)

magnitude_skill=
1-MAE_model/MAE_naive
~~~

暂时只报告，不作为 hard checkpoint constraint。

若 Direction 提升但 Magnitude 长期 worse-than-naive，candidate 不能直接晋升生产模型。

# 15. Direction-protected gradient projection

~~~text
g_D=grad(L_dir,shared)
g_M=grad(L_mag,shared)
~~~

若：

~~~text
dot(g_D,g_M)>=0
~~~

则：

~~~text
g_M_safe=g_M
~~~

若：

~~~text
dot(g_D,g_M)<0
~~~

则：

~~~text
g_M_safe=
g_M-
(dot(g_M,g_D)/(||g_D||^2+eps))*g_D
~~~

最终：

~~~text
g_shared=
lambda_dir*g_D+
lambda_mag*g_M_safe
~~~

注意：

> 这是 Direction-protected asymmetric gradient projection，
> inspired by PCGrad / AMTL，不是原版 symmetric PCGrad。

原则：

~~~text
Direction gradient 永不因 Magnitude 被投影；
只删除 Magnitude 对 primary Direction 的冲突分量。
~~~

# 16. Protected mode 实现约束

- 默认 OFF；
- 仅 gradient_policy=direction_protected 启用；
- vanilla JOINT 不得改变；
- parameter groups 用对象 identity 审计；
- Direction-owned / Magnitude-owned / shared 不得 overlap；
- unknown trainable params => FAIL CLOSED；
- grad clipping/AMP 顺序必须明确；
- protected mode 禁止对全模型做一次 global clipping；
- Direction-owned / Magnitude-owned / Shared 三组必须独立 clipping，防止 Magnitude 通过 clipping coefficient 间接缩放 Direction-owned 更新。

保存：

~~~text
gradient_conflict.parquet
parameter_group_audit.json
protected_projection.parquet
~~~

protected projection telemetry 至少记录：

~~~text
epoch
batch_index
dot_product
post_projection_dot_product
projected
dir_grad_norm
mag_grad_norm
safe_mag_grad_norm
removed_fraction
direction_owned_preclip_norm
magnitude_owned_preclip_norm
shared_preclip_norm
~~~

# 17. Protected mode 单元测试

conflict toy：

~~~text
g_D·g_M<0
=> g_D·g_M_safe>=-eps
=> g_D unchanged
~~~

aligned toy：

~~~text
g_D·g_M>=0
=> g_M_safe==g_M
~~~

ownership：

~~~text
Magnitude 不改变 Direction-owned Temporal grads
Direction 不训练 Magnitude-only params
shared 获得 protected combined gradient
~~~
